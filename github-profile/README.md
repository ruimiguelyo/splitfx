## Featured project — SplitFX

SplitFX is a cross-currency group expense and settlement prototype. It explores how an interface can make money calculations trustworthy instead of hiding quote freshness, rounding, and settlement assumptions.

- Models supported currencies in integer minor units.
- Converts and divides with documented, deterministic rounding behaviour.
- Exposes live, loading, expired, offline, and error quote states over demo rates.
- Derives balances and settlement suggestions through typed Redux selectors.
- Uses React, TypeScript, Redux Toolkit, Webpack, Jest, Testing Library, and Cypress.
- Documents product boundaries, architecture decisions, tests, and accessibility checks.

**Prototype boundary:** SplitFX uses fictional demo data and fixed demo FX rates. It does not connect to a bank, fetch market rates, or move money.
